# Vectora model notebooks

This directory contains the versioned Vectora implementations. For the
project overview, supported workflows, verified configuration, and links to
the technical guides, see the [project README](../README.md).

The current v1.3 notebook set is in
[`Vectora-v1.3-784M/`](Vectora-v1.3-784M/). Its training configuration is
planned, and the saved notebook output does not show the current source
configuration completing. See the [training guide](../docs/training.md) and
[data-preparation guide](../docs/data-preparation.md) for the evidence and
known count discrepancies.
